# Sanitized Crash Bundle

We captured a sanitized crash bundle from `sealbox-2` after a fatal error during attachment sealing.

The bundle includes the public key used and the sealed attachment for incident reproduction. Private key material was redacted.

## Background

The sealed attachment could not be recovered during initial triage. This bundle was preserved to support further analysis and reproduction of the incident.

The original attachment is expected to contain the password for `prize.7z`.
